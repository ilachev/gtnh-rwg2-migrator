COPY READY

Your next world is ready

The original server remains available for rollback. Review the new copy in game before adopting it.

  1. Start the new server with start-rwg2-trial.sh (macOS/Linux) or start-rwg2-trial.bat (Windows), using Java 21.
  2. If you use a system service or scheduled restart, point it at the new folder and its new start script. Existing services are not changed automatically.
  3. Open the new client profile and connect through Multiplayer. Check your bases, claims, inventory, quests, and other dimensions.

To roll back: stop the new server and start the original one. Progress made in the trial is separate.
