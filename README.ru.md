# GTNH RWG2 Migrator

Локальный мастер переноса мира на RWG2: сохранить базы, выбрать запас вокруг приватов, подобрать биомы и смещения, посмотреть будущие стыки и создать проверенную копию сервера и клиента.

## Как запустить

1. Установите **Python 3.11+**, **Git** и полный **JDK 21**. Они должны быть доступны через `python3` (или `py` на Windows), `git`, `java` и `javac`.
2. Скачайте и распакуйте [последний выпуск](https://github.com/ilachev/gtnh-rwg2-migrator/releases).
3. На **macOS** откройте `Start.command`. На **Windows** — `Start.bat`. На **Linux** выполните `sh Start.command` в терминале.
4. Откроется браузер с мастером. Оставьте окно запуска открытым до завершения работы. Язык переключается кнопкой **EN / RU**.

Устанавливать дополнительные Python-библиотеки не нужно. Из папки проекта также можно выполнить `python3 -m gtnh_migrator`.

## Пять шагов

1. **Исходный мир.** Укажите папку остановленного сервера GTNH 2.9.0 для Java 17–26, с RWG2 2.0.6. При желании укажите инстанс Prism/MultiMC с файлом `instance.cfg`: мастер сможет учесть его метки и сделать копию клиента.
2. **Сохранение баз.** Отметьте нужные группы приватов Server Utilities. По умолчанию выбраны все. Укажите запас в чанках: **один чанк — 16 блоков**. Можно добавить места возле меток и задать желаемый биом отдельно для каждой области. Пустое поле биома означает, что важнее подобрать рельеф.
3. **Подбор генерации.** Посмотрите карту сохранения и запустите расчёт. Мастер скачает официальный код генератора, соберёт его и сравнит варианты. На карте можно приближать и перемещать границы; цвет показывает расчётные перепады высот.
4. **Создание копии.** Укажите новые, ещё не существующие папки. Подтвердите остановку исходного сервера и клиента. Мастер скопирует сервер, создаст полный архив мира, проверит его, оставит выбранные чанки и подготовит RWG2 для остальной территории.
5. **Проверка в игре.** Запустите новый сервер через созданный `start-rwg2-trial.sh` или `.bat`, используя Java 21. Откройте новый профиль клиента и подключитесь через Multiplayer. Проверьте базы, приваты, инвентарь, квесты и другие измерения.

Мастер не останавливает и не запускает Minecraft и не меняет системные службы или ежедневные перезапуски. Для удалённого сервера сначала скачайте остановленную копию, затем перенесите готовый результат обратно. При переходе на новый сервер укажите новую папку и новый скрипт в своей службе запуска.

## Что сохраняется

- Выбранные чанки обычного мира сохраняются с исходными сжатыми записями Anvil, постройками и блоками.
- Все остальные измерения сохраняются целиком. Инвентари, квесты, команды и записи приватов проверяются по хешам.
- Полный проверенный бэкап находится в новой папке сервера: `.migration/world-before-rwg2.tar.gz`. Его SHA-256 указан в `.migration/report.json`.
- Исходный мир остаётся на месте. Если он изменится во время подготовки или копирования, мастер откажется завершать перенос.
- В новом клиенте архивируется старая карта обычного мира только для этого сервера. Карты других измерений и метки остаются. Старые кэши руд Visual Prospecting для обычного мира тоже архивируются.

Записи невыбранных приватов сохраняются, хотя их ландшафт может быть перегенерирован. Метки за границей сохранения остаются ориентирами, но их прежнего содержимого может больше не быть.

## Чего ожидать

Подбор смещений **не сглаживает рельеф автоматически**. Он ищет более подходящее расположение биомов и суши. Иногда переход почти незаметен, иногда остаются стены. Оценки строятся по выборочным точкам границы, а покрытие биомом тоже выборочное: в игре возможны реки и небольшие соседние биомы.

Первый расчёт требует интернета и может занять несколько минут или больше при медленной загрузке зависимостей. Затем используется кэш `~/.cache/gtnh-rwg2-migrator`. Анализ идёт на официальном RWG2 **2.0.6**, установленный мод не изменяется. Сид читается из вашего мира; чужие координаты баз и смещения в программу не зашиты.

Если игроки вышли из игры вне выбранной территории, мастер покажет их позиции. Верните их на базу на исходном сервере, остановите его и заново прочитайте мир. Позиции игроков автоматически не меняются.

## Если у вас ещё 2.8.x

Сначала обновите **полную копию** мира до 2.9.0 по [официальному гайду](https://wiki.gtnewhorizons.com/wiki/Installing_and_Migrating), используя [официальные загрузки](https://www.gtnewhorizons.com/downloads/). Проверьте её в игре. Этот проект выполняет следующий этап — перенос ландшафта на RWG2. Он не обновляет моды, не подтверждает удаление неизвестных блоков и не переносит старые кропсы.

Клиент перед использованием мастера должен уже соответствовать версии сервера. Поддерживаются приваты Server Utilities и копирование инстансов Prism/MultiMC. Другие лаунчеры можно настроить вручную, скопировав итоговый `config/rwg2.cfg`.

## Как вернуться

Остановите пробную копию и запустите исходный сервер. Если меняли пути в системной службе, верните прежние. Прогресс в копиях независим. Для дополнительного восстановления есть полный архив мира в `.migration`; распаковывайте его в новую папку с подходящей версией сервера.

При сбое может остаться папка `.partial-*`. Это незавершённая копия для диагностики, запускать её как готовый сервер не следует. Существующие папки мастер не перезаписывает.
